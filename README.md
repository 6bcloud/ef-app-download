# EF Network Download

这里提供 EF Network 客户端各平台安装包下载。

## 下载方式

请进入本仓库的 Releases 页面，下载对应平台的安装包。

## 文件说明

### Windows

- `ef-network-3.7.8-windows-amd64.zip`：Windows 免安装版
- `ef-network-3.7.8-windows-amd64-setup.exe`：Windows 安装版

### macOS

- `ef-network-3.7.8-macos-universal.dmg`：macOS 安装包
- `ef-network-3.7.8-macos-universal.zip`：macOS 压缩包

### Linux

- `ef-network-3.7.8-linux-amd64.AppImage`：Linux AppImage
- `ef-network-3.7.8-linux-amd64.deb`：Debian / Ubuntu

### Android

- `ef-network-mobile-universal.apk`：Android 通用版
- `ef-network-mobile-arm64-v8a.apk`：Android arm64 设备
- `ef-network-mobile-armeabi-v7a.apk`：Android 32 位 ARM 设备
- `ef-network-mobile-emulator.apk`：Android 模拟器版

### Android TV

- `ef-network-tv.apk`：Android TV 版本

### iOS

- `ef-network-ios-arm64.ipa`：iOS arm64 安装包

### OpenWrt

- `luci-app-efnetwork_3.7.8_all.ipk`：OpenWrt LuCI 管理界面
- `efnetwork_3.7.8_aarch64_generic.ipk`：OpenWrt aarch64
- `efnetwork_3.7.8_arm_cortex-a7.ipk`：OpenWrt arm cortex-a7
- `efnetwork_3.7.8_x86_64.ipk`：OpenWrt x86_64

## 校验文件

Release 中附带 `checksums.txt`，可用于核对下载文件是否完整。
